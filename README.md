# Paychain offer monitor

Playwright-скрипт перезавантажує сторінку офферів кожні 2 секунди, знаходить активні оффери у UAH понад заданий поріг і веде журнал оброблених ID. Автопідтвердження вимкнено, доки не буде вказано кнопку `Подтвердить`, що належить саме картці конкретного оффера.

## Встановлення

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
playwright install chromium
Copy-Item config.example.json config.json
```

Відкрийте `config.json` і заповніть `offers_url`. Шаблон уже містить селектори для картки, суми UAH, статусу та кнопки підтвердження з наданого HTML Paychain. Не записуйте сюди токени, cookies або платіжні дані.

## Запуск

### Вікно керування

Щоб керувати запуском кнопками, виконайте:

```powershell
.\.venv\Scripts\python.exe gui.py
```

1. Введіть мінімальну суму в UAH (офер має бути не меншим за неї) і за потреби встановіть прапорець автоматичного підтвердження.
2. Натисніть **«Відкрити Paychain»** і вручну увійдіть у браузері.
3. Натисніть **«Почати моніторинг»** — сторінка почне оновлюватись кожні 2 секунди.
4. Натисніть **«Зупинити»**, коли треба припинити роботу.

### Запуск із термінала

Перший запуск — тільки перевірка, без натискання кнопок:

```powershell
python main.py
```

У вікні Chromium вручну увійдіть у свій обліковий запис. Скрипт оновлюватиме URL зі списком офферів раз на 2 секунди і писатиме в журнал лише нові відповідні оффери.

Після запуску скрипт **не оновлює** сторінку, доки ви не увійдете в акаунт і не натиснете `Enter` у терміналі. Це дає час пройти вхід, код підтвердження або captcha.

Після того як селектори перевірені, автоматичне прийняття вмикається окремо:

```powershell
python main.py --auto-accept
```

Перед цим переконайтеся, що автоматизація дозволена правилами сервісу та що ви маєте право виконувати ці операції. У разі captcha, помилки або зміни інтерфейсу програма не має повторно натискати кнопку.

## Журнали

- `logs/activity.log` — короткі рішення по офферах: `ПРОПУЩЕНО`, `ПІДХОДИТЬ, АЛЕ НЕ ПРИЙНЯТО`, `ПРИЙНЯТО` або `НЕ ПІДТВЕРДЖЕНО`.
- `logs/bot.log` — повний технічний журнал для діагностики.

## Налаштування селекторів

З браузера DevTools скопіюйте стабільні CSS-селектори для:

- контейнера одного оффера (`offer_selector`);
- ID оффера в атрибуті (`offer_id_attribute`);
- суми, валюти, статусу всередині картки;
- кнопки підтвердження всередині картки.

Приклад налаштувань у `config.example.json` не є селекторами Paychain, а лише шаблоном. Це зроблено, щоб програма не натиснула неправильну кнопку на зміненій сторінці.
